# JWU NCSA

The cybersecurity club at Johnson & Wales University. We build and run hands-on security projects for
students, starting with CyberPaw, our capture-the-flag (CTF) platform.

## Projects

| Project | What it is |
|---|---|
| [CyberPaw](https://github.com/JWU-NCSA/CyberPaw) | The club's CTF site at [jwucyberlab.org](https://jwucyberlab.org). Challenges, scoreboard and the setup guide for running it. |

## Get involved

- Play challenges at [jwucyberlab.org](https://jwucyberlab.org).
- Want to contribute? Read the [contributing guide](https://github.com/JWU-NCSA/.github/blob/main/CONTRIBUTING.md).
- Found a security problem in one of our projects? Follow the
  [security policy](https://github.com/JWU-NCSA/.github/blob/main/SECURITY.md). Do not open a public issue.
