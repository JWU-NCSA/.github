# Security policy

## Reporting a vulnerability

Please do not report security problems in public issues, pull requests or discussions.

Report them privately instead: open the repo on GitHub, go to the **Security** tab and click **Report a
vulnerability**. Only the reporter and the club officers can see the report.

Include what you found, how to reproduce it and what an attacker could do with it. We will reply as soon as
we can and keep you updated while we fix it.

## Scope

In scope: the code in JWU NCSA repos and the CyberPaw platform at [jwucyberlab.org](https://jwucyberlab.org).

Solving CTF challenges as intended is not a vulnerability. Bugs that let you get flags without solving the
challenge, read other players' data, change the scoreboard or reach the server behind the site are.

Do not run denial-of-service attacks, automated scanners at high volume or social engineering against club
members while testing.
